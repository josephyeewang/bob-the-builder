# Module distribution contract

A capability has one portable implementation under skills/<id>. Personal callers supply private context through adapters. An explicit export registry includes only reviewed files and licenses. Each independent ZIP includes its entrypoint, resource closure, install guidance and hashes bound to the source revision. A current catalogue points to complete versioned release assets. Downloads are snapshots; no installed-copy update is implied.

New modules use the same registry and checks. Optional companion modules never become hidden mandatory dependencies. Registering a module does not automatically list it on another product surface. Existing private records and personal discovery remain private and behavior-compatible.
