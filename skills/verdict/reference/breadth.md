# Match comparison depth to the decision

First infer the user's reason for sending the tool from their words and context; name that focus in one sentence. If it is unknown, inspect broadly rather than force an interview or assume adoption is the only goal.

- **adopt / category scan:** search alternatives by job fit, normally three or more genuine candidates plus the user's actual implementation. If fewer exist or access is limited, record the search and gap; don't pad.
- **learn / copy a named repo or component:** concentrate on source execution and destination. Compare our actual equivalent and a relevant implementation alternative when it changes the choice; a three-tool landscape is not required.
- **recheck:** inspect changed source, old blockers, destination changes and unresolved opportunities. Expand alternatives only if those changes reopen the original choice.

Use behavior/source-symbol queries as well as category names. Include small/new projects and substitutes outside the category. Registries, practitioner discussions and relevant directories can broaden discovery; snowball useful keywords once. No stars/download threshold for admission or ranking. Category scans distinguish screened candidates from full reviews.

Compare job fit, useful implementation/visual/workflow example, inspected evidence, adaptation/operating burden, security unknowns and cost. Name specific stronger parts. Check actual delivered behavior rather than an imported library's feature list.

Usage, age, contributors, reputation, release activity and attention belong in the independent qualitative assessment. Missing registry usage does not invalidate source evidence. Optional statistics need source/window and honest labels (downloads are not users). Discovery order isn't a quality judgment.

Record request_mode and alternative_search.scope_reason. Targeted learn/recheck requests can legitimately have no external queries if the reason is stated. Don't call unavailable searches completed. No “unique,” “best,” or “nobody does this” claim without adequate search evidence. Competition validates pain.
